# Manual Randomizer Setup Guide

## What You'll Need

  - Archipelago

  - Nintendo Switch

    - Assumes you have both Joycons, or some way to connect at least two controllers if absolutely necessary

  - Kirby Star Allies



## Highly Recommended

  - Universal Tracker (For handling required item amounts)



## Installation and Prerequisites

  - Make sure both this apworld and the Universal Tracker apworld are placed in your Archipelago custom worlds directory. 

  - In general, **it is highly recommended to use a 100% save file** for running this manual of Kirby Star Allies. At minimum, the following are required:

    - **Every stage in Story Mode must be accessible.** This includes each of the Dream Palaces as well as the Ability Planet.

    - If you wish to include Heroes in Another Dimension, make sure you've already completed the mode with **every Friend Heart collected** to ensure full accessibility throughout the run.



## Joining a MultiWorld Game

  1. Open the Archipelago Launcher.

  2. Scroll down to "Manual Client" and select "Open". If you can't find it, make sure the apworld is properly installed and select either the "All" or "Client" section from the launcher's sidebar.

  3. **BEFORE JOINING THE SERVER**, make sure the "Manual Game ID" just below the port is set to "Manual\_KirbyStarAllies\_Poyu"

  4. Enter you server and port in the bar up top and select "Connect".
  
  5. When prompted, enter your player name in the "Command" box at the bottom.

  6. If all goes well, you should now be connected!



## About Multiplayer

Kirby Star Allies is primarily a multiplayer game. While the vast majority of checks and logic scenarios should be entirely possible in single player, some intervention might be necessary to get around some of the AI's eccentricities (ex. Adeleine and Ribbon will usually prioritize Rock Painter over Curling if you have Stone). Keep this in mind if you happen to get stuck somewhere. Some solutions won't always be obvious.

If you wish to run a single instance of this manual apworld with local co-op, make sure you have at least one ally to start with so your buddy can join right away. It might be worth considering adding a specific character or ability to your starting inventory if there's someone they really like playing as (start_inventory_from_pool is recommended).
